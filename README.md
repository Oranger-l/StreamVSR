# StreamVSR project page

Static project page for *StreamVSR: Unified Streaming Visual Model for Video Super-Resolution, Stereo Synthesis, and Refocusing*.

Serve it with GitHub Pages from the repository root, or locally with:

```bash
python3 -m http.server 8000
```

World-model videos shown on the page belong to their creators (HelixWorld, LingBot-World, SANA-WM, SolarWM); see the credits at the bottom of the page.
